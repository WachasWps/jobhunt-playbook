# Base resumes

Put your base resume variants here as Markdown (for example `First_Last_Resume_backend.md`, `First_Last_Resume_ai.md`), then render them with `bash resume/templates/render-pdf.sh`. Everything in this folder except this README is gitignored.

Each base resume must already pass `fact-check.py`. Tailored per-JD copies go in `tailored/YYYY-MM/<company-role>/`, not here.
