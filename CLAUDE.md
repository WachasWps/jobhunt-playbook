# CLAUDE.md

Read `AGENTS.md` first. It is the full operating manual for this repo and applies to Claude Code too.

Key rules, in short:

1. **No fabrication.** Every claim traces to `profile/factsheet.md`. Run `bash resume/templates/preflight.sh <tailored-folder>` before anything is sent.
2. **No em-dashes, en-dashes or middle dots** in anything you write. Use commas, periods, hyphens or `|`.
3. **The user submits and sends.** Never click a final Submit or send an email or DM yourself.
4. **Captchas, OTPs and logins go to the user.** Never solve or bypass them.
5. **Honest knockout answers.** If the truth disqualifies, skip the role.
6. **Discretion.** Truthful current CTC, no current-employer internals, no public Open-to-Work banner. See `docs/07-comp-and-discretion.md`.
7. **Verify every email** (published, GitHub commit, proven pattern, `dig MX`). Unverified means LinkedIn DM.
8. **Caps.** 15 to 20 cold emails a day, each paired with a LinkedIn DM. Tailor every application.
9. **Subagents get no browser.** Only the main session drives the user's Chrome.
10. **Secrets stay secret.** Never print or commit tokens, keys or session files.

Start each session with W0 in `AGENTS.md`: read the factsheet and trackers, surface what is due today, then act.
